# Product Structure

## Landing Page Sections

- `hero/` — Hero and primary call to action
- `why-bitget/` — Platform overview and key benefits
- `services/` — Bitget services and product categories
- `trading/` — Trading related content
- `rewards/` — Rewards and promotions
- `getting-started/` — Simple onboarding flow
- `referral/` — Affiliate/referral conversion section
- `faq/` — Frequently asked questions
- `footer/` — Footer, disclosures, and important links

## Build Order

Feature 1: Project foundation + Hero

Feature 2: Why Bitget

Feature 3: Bitget Services

Feature 4: Trading

Feature 5: Rewards

Feature 6: Getting Started

Feature 7: Referral CTA

Feature 8: FAQ

Feature 9: Footer and disclosures

Feature 10: Responsive polish and final QA
