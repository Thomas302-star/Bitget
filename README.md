# Bitget Affiliate Landing Page

A feature-by-feature landing page project focused on presenting Bitget services and directing interested visitors to the appropriate Bitget destination.

## Product Structure

1. Hero
2. Why Bitget
3. Bitget Services
4. Trading
5. Rewards
6. Getting Started
7. Referral CTA
8. FAQ
9. Footer and disclosures
10. Responsive polish and final QA

## Build Approach

The product will be built one feature at a time. Each feature will be implemented, reviewed, and tested before moving to the next feature.

No feature implementation is included in this scaffold commit.
